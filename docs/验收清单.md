## 8. 命令验收

```powershell

python manage.py makemigrations --check --dry-run
python manage.py migrate
python manage.py seed_demo --reset
python manage.py test warehouse
python manage.py runserver
```

- `check`：0 issues；

## 10. 备注

- 演示密码为弱口令，部署前必须修改；
- 生产建议使用 MySQL、关闭 DEBUG、配置对象存储与 HTTPS；
- 当前为单级验收/审核；多级审批、库存预留、批量导入属于扩展项；
- MySQL 部署需要安装 `mysqlclient`；
- `sql/schema_sqlite.sql` 为结构参考导出，正式建表以 Django 迁移为准。
