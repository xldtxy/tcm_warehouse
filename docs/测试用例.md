## 2. 手工验收用例

### 2.1 演示前准备

```powershell
python manage.py migrate
python manage.py seed_demo --reset
python manage.py runserver
```

浏览器打开 <http://127.0.0.1:8000/>，使用 `keeper / keeper123` 登录。

### 2.2 验收场景

| 编号 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |

## 3. 边界与异常测试

| 场景 | 结果 |
| --- | --- |
| 数量为 0 / 负数 | 表单与服务层拦截 |
| 数量超过当前批次库存 | 建单/提交阶段拦截；执行阶段再次校验 |
| 移出与移入相同 | 表单与服务层双重拦截 |
| 移出与移入跨仓库 | 表单与服务层双重拦截 |
| 库存行被并发改小 | 执行事务回滚，单据保持 approved，库存不出现负数 |
| 重复点击“确认执行” | 第二次因状态不是 approved 被拦截，流水不重复 |
| 单据已取消后追加异常 | 拦截 |
| 已完成单据追加异常 | 允许，保留事后说明 |
| 非申请人删除草稿 | 403 |
| 访客上传附件 | 403 |
| 附件同时关联移库/出库 | 模型 `clean()` 拦截 |
| 附件超过 5 MB | 表单/模型校验拦截 |

## 4. 验收结论

- 学生 1-5 的全部功能包可演示、可测试；
- 71 个自动化测试全部通过；
- 入库/出库/移库状态流转、库存联动、权限分离、查询导出形成闭环；
- 演示数据覆盖全部单据状态，可直接用于课堂验收。
