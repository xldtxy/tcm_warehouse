# 课堂演示脚本（完整版，约 9 分钟）

## 0. 演示前准备

```powershell
cd C:\Users\33139\Desktop\zuoye\demo
python manage.py seed_demo --reset
python manage.py runserver
```

浏览器打开 <http://127.0.0.1:8000/>。建议准备两个无痕窗口，分别登录 `keeper` 和 `manager`。

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| `keeper` | `keeper123` | 仓管员 |
| `manager` | `manager123` | 仓库主管 |
| `admin` | `admin123` | 管理员 |
| `viewer` | `viewer123` | 只读访客 |

## 1. 全系统工作台（40 秒）

用 `keeper` 登录，介绍：

- 待处理 3、待执行 3、库存批次 12；
- 四个模块入口：药材与库存、入库管理、移库/出库、查询审计；
- 最近业务单据同时展示入库、移库、出库；
- 低库存提醒与操作动态。

> 这套系统完整覆盖学生 1-5：基础资料、药材库存、入库、移库出库、查询审计。

---

## 2. 学生 1：注册、用户、仓库、权限（1 分 30 秒）

1. 打开 `/accounts/signup/`，演示注册表单（可不真正提交，或提交一个新账号）。
   - 说明：新用户默认为只读访客，必须由管理员分配岗位。
2. 切换到 `admin`，进入“用户管理”：
   - 用户列表按岗位统计；
   - 新建用户/编辑岗位/停用账号/重置密码。
3. 进入“仓库与库位”：
   - 展示 WH01 中心饮片仓与 WH02 城南分仓；
   - 说明库位编码同仓库唯一，有库存/单据时禁止删除。
4. 进入“角色权限”，选择“仓管员”：
   - 左侧菜单、右侧接口权限矩阵；
   - 演示勾选/取消“库存批次”并保存；
   - 说明超级管理员始终拥有全部权限，避免锁死系统。

---

## 3. 学生 2：药材与库存（1 分钟）

1. 打开“药材资料”：搜索“黄芪”，展示编码/规格/安全库存/当前库存/批次。
2. 打开黄芪详情：总库存、批次、最近流水。
3. 打开“库存批次”：
   - 按仓库、药材、低库存筛选；
   - 打开一个批次，展示当前库存与完整流水；
   - 编辑库存时，数量变化必须填写原因，并生成 ADJUST 流水，不能直接覆盖历史。

---

## 4. 学生 3：入库全流程（2 分钟）

1. 用 `keeper` 打开“入库管理 → 新建入库单”。
2. 选择供应商“安徽亳州药材合作社”、仓库 WH01、入库日期默认今天。
3. 填写两条明细：
   - 黄芪 / HQ20261020 / A-01 / 20 kg / 58 元；
   - 白术 / BZ20261020 / B-01 / 8 kg / 42 元。
4. 点击“保存并提交验收”。
5. 切换到 `manager`，打开该入库单：
   - 查看明细、合计金额、状态轨迹；
   - 填写验收意见，点击“验收通过”；
   - 强调验收通过只授权，不直接加库存。
6. 切回 `keeper`，点击“确认入库”：
   - 状态变“已入库”；
   - 库存批次增加，生成 INBOUND 流水；
   - 同批次已存在时自动累加。

---

## 5. 学生 4：移库 / 出库（1 分 30 秒）

1. 用 `keeper` 新建移库：黄芪 A-01 → B-02，数量 10。
2. 右侧库存预检显示可用批次与数量。
3. 保存并提交；`manager` 审核通过；`keeper` 确认完成。
4. 展示：
   - 源库位减少、目标库位增加，总库存不变；
   - 两条库存流水；
   - 操作轨迹与异常备注入口。
5. 打开一张已审核出库单，确认出库，展示库存扣减。
6. 强调：库存不足/重复确认会整笔回滚。

---

## 6. 学生 5：查询、导出、日志（1 分钟）

1. 打开“库存查询”：
   - 按时间、操作人、药材、业务对象筛选；
   - 展示入库/出库合计、流水条数、库存分布、Top 药材；
   - 双柱状图展示每日出入库趋势。
2. 点击“导出 CSV”，说明 UTF-8 BOM，Excel 直接打开中文。
3. 点击“打印页面”，展示打印单的汇总/明细/签字栏。
4. 打开“操作日志”：
   - 按人员、动作、单据类型筛选；
   - 展示创建/提交/审核/完成/异常轨迹；
   - 导出日志 CSV。

---

## 7. 权限与只读角色（30 秒）

1. 用 `viewer` 登录：
   - 只能看到工作台、单据、库存、查询、日志；
   - 没有新建/审核/执行按钮；
   - 直接访问新建 URL 返回 403。
2. 说明菜单与接口权限由 `RolePermission` 数据库配置，侧边栏和视图同步生效。

## 9. 演示应急

| 情况 | 处理 |
| --- | --- |
| 数据被改乱 | `python manage.py seed_demo --reset` 后刷新 |
| 端口占用 | `python manage.py runserver 8001` |
| 忘记密码 | 重新执行 `seed_demo --reset` |
| 入库单没有明细行 | 点击“添加明细”，或刷新建单页 |
| CSV 中文乱码 | 已使用 UTF-8 BOM；用 Excel 直接打开 |
