# 全模块功能说明（学生 1-5）

## 1. 系统边界

本草仓是一套面向中药饮片仓库的课程实践系统，覆盖五个功能包，所有模块共享同一套药材、库位、批次、用户与权限数据。

| 功能包 | 负责人 | 主要页面 | 关键数据 |
| --- | --- | --- | --- |
| 学生 1 | 用户与仓库资料 | 注册/登录、用户管理、仓库库位、供应商、角色权限 | User、UserProfile、Warehouse、StorageLocation、Supplier、RolePermission |
| 学生 2 | 药材与库存管理 | 药材资料、库存批次、药材/库存详情 | Herb、StockBatch、StockMovement |
| 学生 3 | 入库管理 | 入库单列表、建单/编辑、详情、验收/入库 | InboundOrder、InboundItem |
| 学生 4 | 移库出库管理 | 移库/出库列表、详情、审核、执行、异常附件 | TransferOrder、OutboundOrder、OrderAttachment |
| 学生 5 | 库存查询与日志 | 库存查询、统计图表、操作日志、导出/打印 | StockMovement、OrderStatusLog |

## 2. 学生 1：用户、基础资料与权限

### 2.1 注册、登录、退出

- 注册页 `/accounts/signup/`：账号、姓名、邮箱、电话、部门、密码；
- 新用户角色固定为“只读访客”，需管理员在用户管理中分配岗位；
- 登录页 `/accounts/login/` 支持演示账号一键填入和 `next` 回跳；
- 退出使用 POST + CSRF，避免 GET 退出。

### 2.2 用户管理

- 仅 `user.manage` 权限（默认管理员）可访问；
- 支持按关键字/岗位/启用状态筛选、分页；
- 创建用户、分配角色、启停账号、重置密码；
- 当前登录账号不能停用自己；
- 超级管理员的超管身份不会被编辑表单降级。

### 2.3 仓库、库位、供应商

- 仓库：编码唯一、名称、地址、启停；
- 库位：所属仓库、库位编码（同仓库唯一）、名称、库区、启停；
- 供应商：名称、联系人、电话、地址、启停；
- 删除保护：有关联库位、库存、入库单、移库/出库单时拒绝删除，提示改为停用；这是为了不破坏历史可追溯性。

### 2.4 角色、菜单、接口权限

`RolePermission` 保存每个角色的：

- `menus`：侧边栏可见的菜单 key；
- `permissions`：接口/动作权限字典，例如 `inbound.create`、`transfer.audit`、`export.data`。

默认配置位于 `warehouse/access.py`。管理员在 `/settings/roles/` 保存后：

- 侧边栏立即按菜单配置显示；
- 视图通过 `has_perm()` 校验对应接口；
- 菜单与查看权限自动保持一致（例如勾选“药材资料”会自动开启 `herb.view`）；
- 超级管理员始终拥有全部权限，避免锁死。

## 3. 学生 2：药材与库存

### 3.1 药材

- 字段：编码、名称、规格、单位、类别、安全库存、启用状态；
- 列表：关键字、类别、状态筛选、分页；
- 详情：总库存、批次列表、最近 30 条流水；
- 删除：有库存/入库/移库/出库引用时拒绝，建议停用。

### 3.2 库存批次

- 唯一维度：药材 + 库位 + 批次；
- 新建批次时写“期初入库”流水；
- 编辑：维护生产日期/有效期；库存数量通过“调整后数量 + 原因”产生 ADJUST 流水，前后值可查；
- 列表：关键字、仓库、药材、低库存筛选、分页；
- 详情：批次库存、安全库存、库位、完整流水；
- 删除：仅库存为 0 且没有任何流水的空批次可删。

## 4. 学生 3：入库管理

### 4.1 建单与明细

- 表头：供应商、入库仓库、入库日期、随货同行单号、说明；
- 明细：药材、批次号、目标库位、数量、单价、生产日期、有效期、备注；
- formset 动态增加/删除明细；
- 校验：至少一条明细、数量 > 0、库位属于入库仓库、同单内药材/批次/库位不能重复、日期先生产后失效。

### 4.2 状态流转

| 状态 | 操作 | 权限 | 效果 |
| --- | --- | --- | --- |
| draft | 编辑/删除草稿 | 申请人 + inbound.create | 不改库存 |
| draft/rejected | 提交验收 | 申请人 | → pending |
| pending | 验收通过 | inbound.audit | 记录验收人/意见 → approved |
| pending | 驳回 | inbound.audit | 原因必填 → rejected |
| approved | 确认入库 | inbound.execute | 逐条增库存 + INBOUND 流水 → completed |
| draft/pending/approved | 取消 | 申请人/主管 | → cancelled |

确认入库使用事务和库存行锁，同一批次已存在则累加，否则新建批次并继承明细的生产/有效期。

## 5. 学生 4：移库出库管理

完整说明见 [`学生4_功能说明.md`](学生4_功能说明.md)。摘要：

- 移库：同仓库位移动，总库存不变；
- 出库：领用/报损/调拨/其他；
- 状态：draft → pending → approved → completed，可 rejected/cancelled；
- 审核与执行岗位分离，禁止自审；
- 执行时锁定库存、重复执行保护、库存不足回滚；
- 异常备注追加、附件（≤5 MB）、完整状态/库存轨迹。

## 6. 学生 5：查询、统计与审计

### 6.1 库存查询

筛选条件：

- 关键字：药材/批次/单号/库位/备注；
- 时间范围；
- 操作人；
- 药材；
- 业务对象：入库单/移库单/出库单/手工期初；
- 变动类型：期初/采购入库/出库/移出/移入/盘点调整。

统计：

- 入库合计、出库合计、流水条数；
- 当前库存批次、总库存、低库存数；
- 按日出入库双柱状图（排除手工期初，避免压平业务波动）；
- 仓库分布、Top 药材；
- 明细分页。

### 6.2 操作日志

- 按操作人、动作、单据类型、时间、关键字筛选；
- 记录创建、提交、审核、驳回、完成、取消、异常、附件等动作；
- 可分页、导出 CSV。

### 6.3 导出与打印

- CSV 使用 UTF-8 BOM，Excel 直接打开中文不乱码；
- 库存查询打印页包含标题、筛选条件、汇总、明细、签字栏，可直接打印/保存 PDF；
- 导出接口受 `export.data` 权限控制。

## 7. 数据模型关系

```text
User 1─1 UserProfile
Role 1─1 RolePermission

Warehouse 1─n StorageLocation 1─n StockBatch n─1 Herb
Supplier 1─n InboundOrder 1─n InboundItem n─1 Herb / StorageLocation
InboundOrder / TransferOrder / OutboundOrder 1─n OrderStatusLog（多态关联）
StockBatch 1─n StockMovement
TransferOrder / OutboundOrder 1─n OrderAttachment
```

`StockMovement.order_type + order_no + order_id` 把库存流水关联回业务单据；`OrderStatusLog` 用 `order_type + order_id` 统一记录三类单据轨迹。

## 9. 与小组项目合并

- `warehouse` 是独立 app，可整体并入；
- 若其他同学已有 `Herb / StockBatch`，可只迁移 `InboundOrder / InboundItem / RolePermission` 并调整外键；
- 学生 5 的查询/统计/导出直接读 `StockMovement` 与 `OrderStatusLog`，不依赖具体页面；
- 权限系统通过 `has_perm` 和模板 `role_permissions` 统一扩展，新增菜单只需在 `access.py` 增加定义和 URL 映射。
